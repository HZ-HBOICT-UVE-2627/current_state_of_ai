# Current State of AI

Playbook and course materials for the "Current State of AI" module.

## Repository structure

- [`docs/`](docs/) — Course documentation
  - [`playbook.md`](docs/playbook.md) — Course goals, weekly schedule, group work rules, hackathon info, demo day, and assessment/grading details
  - [`grading_rubric.md`](docs/grading_rubric.md) — Exam grading form used to assess portfolios
  - [`portfolio_template.md`](docs/portfolio_template.md) — Template students fill in for their portfolio submission
- [`code/`](code/) — Student/group code produced during the course (e.g. hackathon project)

## Course overview

Students work in pairs over the course week to build an understanding of AI and how it can be applied within their own field. The week includes guest lectures, a hackathon where teams build an AI-powered application, and a demo day where invited companies give feedback. The course concludes with an assessment based on a submitted portfolio and group presentation.

See [`docs/playbook.md`](docs/playbook.md) for the full schedule and requirements.
